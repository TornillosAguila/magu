# Distribuciones Magu — Landing Page

**Slogan:** Distribuciones Magu, tu ferretería de confianza.

## Contenido del paquete

- `index.html` — La landing page completa. Es **un solo archivo autocontenido**:
  todos los logos (Magu + 18 marcas) van embebidos. Se abre con doble clic y
  funciona sin servidor ni conexión para los assets.
- `assets/` — Logos en alta resolución con fondo transparente, por si quieres
  reutilizarlos en otros materiales (redes, papelería, etc.).
  - `logo_magu_indigo.png` — Logo en índigo, para fondos claros.
  - `logo_magu_crema.png` — Logo en crema, para fondos oscuros.
  - `marcas/` — Los 18 logos de marcas, limpios y normalizados.

## Cómo publicarlo

Solo necesitas subir `index.html` a tu hosting (Hostinger, Netlify, Vercel,
GoDaddy, etc.). No requiere base de datos ni backend.
